AWS Image Compression Pipeline

Serverless Image Optimization Platform

AWS Lambda • Amazon S3 • API Gateway • CloudFront • Python

A project-based serverless application that automatically compresses images using AWS Lambda, stores optimized files in Amazon S3, and securely delivers downloads through Presigned URLs.

Project source code and implementation details are available on GitHub. Live hosting is currently inactive.

Previous Deployment

The application was previously delivered through Amazon CloudFront. The AWS hosting environment is currently inactive; the source code and architecture remain available for review.

Architecture

The workflow begins with image upload through the frontend. API Gateway invokes Lambda, images are stored in an S3 input bucket, processed automatically, saved to an output bucket, and securely delivered back to users.

My Contribution & Implementation

I implemented the image-processing workflow using Python and an AWS Lambda function. The solution accepts uploaded image files, processes them with an image library, and writes optimized output to the designated storage location. The surrounding workflow connects upload events, processing, and output retrieval.

Technical Architecture Walkthrough

An image is uploaded to the input S3 bucket. The object-created event invokes the Lambda function, which validates and processes the image before saving the compressed result to the output bucket. API Gateway and CloudFront were part of the earlier access and delivery design. The AWS resources are no longer hosted, but the implementation and architecture remain documented in the repository.

Development Decisions & Learning

The event-driven approach avoids keeping an application server running for each image-processing request. The project helped me understand event notifications, Lambda execution, file validation, image transformation, storage permissions, and the importance of handling unsupported or invalid image inputs.
