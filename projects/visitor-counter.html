AWS Serverless Visitor Counter

AWS Cloud Project

A cloud-native serverless application built using AWS services to track and display live website visitors.

Project Overview

This project was developed to gain hands-on experience with AWS serverless architecture. The application automatically stores and updates website visitor counts using AWS Lambda and DynamoDB.
